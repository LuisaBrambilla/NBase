Request Flow

User → Browser loads static files from Azure Blob Storage → JavaScript calls API at App Service / Container Apps → FastAPI processes request → Queries PostgreSQL on Azure VM → Returns JSON response

Admin routes require a JWT Bearer token (obtained via /admin/login). Public routes (/public/*) are open.

7. Backend Code

api/main.py (518 lines)

FastAPI application entry point. Defines all routes, request/response models, CORS middleware, and admin auth middleware.

Key components:

  • CORS: Configured via CORS_ORIGINS env var
  • Auth Middleware: Intercepts all /admin/* routes (except login/register) and validates JWT
  • Pydantic Models: AdminRegisterPayload, AdminLoginPayload, AdminRegisterConfirmPayload, NormaVerificacaoPayload, AdminPerfilUpdatePayload, AdminSenhaUpdatePayload, AdminMfaConfirmPayload, AdminMfaDisablePayload
  • Password Rules: Must have uppercase + lowercase + number + special character

api/auth.py (120 lines)

Authentication utilities — zero external dependencies (no PyJWT, no pyotp).

  • JWT: Manual HS256 implementation (sign, verify, expiry check)
  • Password Hashing: PBKDF2-SHA256 with 200,000 iterations + random 16-byte salt
  • TOTP/MFA: Manual RFC 6238 implementation (base32 secret, SHA1 HMAC, 6-digit code, ±1 window)
  • OTPAuth URI: Generates otpauth://totp/ URIs for QR code scanning

9. Deployment

Docker Build & Push

# Build image in Azure Container Registry (no local Docker needed)
az acr build --registry crgen360 --resource-group DemoGoverno \
  --image gen360-api:latest --file Dockerfile . --no-logs

# Update App Service (pulls new image)
az webapp restart --resource-group DemoGoverno --name app-gen360-api

# Update Container App
az containerapp update --name ca-gen360-api --resource-group DemoGoverno \
  --image crgen360.azurecr.io/gen360-api:latest

Frontend Deployment

# Upload frontend files to Azure Blob Storage static website
az storage blob upload-batch \
  --account-name stgen360frontend \
  --destination '$web' \
  --source admin_frontend/
