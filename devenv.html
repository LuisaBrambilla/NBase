3. Quick Start (Copy-Paste)

Open PowerShell, cd into the Gen360 project root, and run:

# 1) Start PostgreSQL
docker run -d --name gen360-postgres `
  -e POSTGRES_DB=normas `
  -e POSTGRES_USER=postgres `
  -e POSTGRES_PASSWORD=Newpr2026@ `
  -p 5432:5432 `
  postgres:16

# 2) Wait for PG to be ready
Start-Sleep -Seconds 5

# 3) Apply schema + migrations
Get-Content db\models.sql -Raw | docker exec -i gen360-postgres psql -U postgres -d normas
Get-Content db\migracoes\002_origem_dodf.sql -Raw | docker exec -i gen360-postgres psql -U postgres -d normas
Get-Content db\migracoes\003_admin_mfa.sql -Raw | docker exec -i gen360-postgres psql -U postgres -d normas
Get-Content db\migracoes\004_verificacao_normas.sql -Raw | docker exec -i gen360-postgres psql -U postgres -d normas

# 4) Install Python dependencies
pip install -r requirements.txt

# 5) Set env vars & start server
$env:DB_HOST="localhost"
$env:DB_PORT="5432"
$env:DB_NAME="normas"
$env:DB_USER="postgres"
$env:DB_PASSWORD="Newpr2026@"
$env:JWT_SECRET="local-dev-secret"
$env:CORS_ORIGINS="*"

python -m uvicorn api.main:app --host 0.0.0.0 --port 8000 --reload

# 6) Open in browser:
#    API Docs:  http://localhost:8000/docs
#    Health:    http://localhost:8000/health
#    Frontend:  open admin_frontend\index.html in browser
✅ That's it! The API will be at http://localhost:8000 with hot-reload enabled. The frontend auto-detects localhost and connects to it.

4. Step-by-Step Setup

1 Start PostgreSQL via Docker

Create and start a PostgreSQL 16 container with the normas database pre-created:

docker run -d --name gen360-postgres `
  -e POSTGRES_DB=normas `
  -e POSTGRES_USER=postgres `
  -e POSTGRES_PASSWORD=Newpr2026@ `
  -p 5432:5432 `
  postgres:16

Verify it's running

docker ps --filter name=gen360-postgres --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"
NAMES               STATUS          PORTS
gen360-postgres     Up 2 minutes    0.0.0.0:5432->5432/tcp

Wait for readiness

docker exec gen360-postgres pg_isready -U postgres
/var/run/postgresql:5432 - accepting connections
💡 Persistent Data: By default, this container stores data in an anonymous Docker volume. If you need data to survive docker rm, add -v gen360-pgdata:/var/lib/postgresql/data to the run command.

2 Apply Database Schema & Migrations

The schema creates the norma and admins tables plus necessary extensions, indexes, and triggers.

# Base schema
Get-Content db\models.sql -Raw | docker exec -i gen360-postgres psql -U postgres -d normas

# Migrations (apply in order)
Get-Content db\migracoes\002_origem_dodf.sql -Raw | docker exec -i gen360-postgres psql -U postgres -d normas
Get-Content db\migracoes\003_admin_mfa.sql -Raw | docker exec -i gen360-postgres psql -U postgres -d normas
Get-Content db\migracoes\004_verificacao_normas.sql -Raw | docker exec -i gen360-postgres psql -U postgres -d normas

Expected output

CREATE EXTENSION   (uuid-ossp, pg_trgm)
CREATE TABLE       (norma, admins)
CREATE INDEX       (6 indexes)
CREATE FUNCTION    (atualizar_data)
CREATE TRIGGER     (trg_atualizar_norma)
ALTER TABLE        (migrations applied)

Verify tables exist

docker exec gen360-postgres psql -U postgres -d normas -c "\dt"

9. Troubleshooting

🔴 Docker: "failed to connect to the docker API"

Cause: Docker Desktop engine is not running. 
# 1. Start Docker Desktop
Start-Process "C:\Program Files\Docker\Docker\Docker Desktop.exe"

# 2. Wait 10–15 seconds, then verify
docker info | Select-String "Server Version"

# 3. If still failing, try switching context
docker context ls
docker context use desktop-linux   # or "default"

🔴 Port 5432 already in use

Cause: Another PostgreSQL instance or container is using port 5432. 
# Check what's using the port
netstat -ano | findstr :5432

# If it's an old container, remove and recreate
docker rm -f gen360-postgres
docker run -d --name gen360-postgres ...  (full command from Quick Start)

# Or use a different port
docker run -d --name gen360-postgres -p 5433:5432 ...
# Then set $env:DB_PORT="5433"

🔴 Container exists but is stopped

# Check container status
docker ps -a --filter name=gen360-postgres

# Restart it (data is preserved)
docker start gen360-postgres

# Verify readiness
docker exec gen360-postgres pg_isready -U postgres

🔴 "password authentication failed"

Cause: Mismatched password between env vars and container. 
# Verify the password set in the container
docker exec gen360-postgres psql -U postgres -c "SELECT 1"

# If the container was created with a different password,
# recreate it (this destroys data):
docker rm -f gen360-postgres
docker volume prune  # optional: clean orphaned volumes
# Then re-run the docker run command

🔴 "relation 'norma' does not exist"

Cause: Schema was not applied to the database. 
# Re-apply schema and migrations
Get-Content db\models.sql -Raw | docker exec -i gen360-postgres psql -U postgres -d normas
Get-Content db\migracoes\002_origem_dodf.sql -Raw | docker exec -i gen360-postgres psql -U postgres -d normas
Get-Content db\migracoes\003_admin_mfa.sql -Raw | docker exec -i gen360-postgres psql -U postgres -d normas
Get-Content db\migracoes\004_verificacao_normas.sql -Raw | docker exec -i gen360-postgres psql -U postgres -d normas

🔴 "ModuleNotFoundError: No module named 'fastapi'"

pip install -r requirements.txt
# If using a venv, make sure it's activated first:
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

🔴 API starts but DB queries fail silently

# Check that env vars are actually set
Write-Host "DB_HOST=$env:DB_HOST DB_PORT=$env:DB_PORT DB_NAME=$env:DB_NAME DB_USER=$env:DB_USER"

# Test DB connection directly with Python
python -c "from db.db import get_connection; c=get_connection(); print('OK'); c.close()"

🔴 CORS errors in the browser console

# Ensure CORS_ORIGINS is set to "*" for local dev
$env:CORS_ORIGINS="*"

# If serving frontend from a specific port, add it explicitly
$env:CORS_ORIGINS="http://localhost:3000,http://localhost:5500"

🔴 Frontend shows "Erro ao conectar" or "Network Error"

  1. Confirm the API server is running: curl http://localhost:8000/health
  2. Check browser DevTools → Network tab for the failing request
  3. Ensure config.js resolves to http://localhost:8000 (check console log)
  4. If opening HTML via file://, CORS may block requests — use a local HTTP server instead

🟡 Cleaning up everything (fresh start)

# Stop and remove container + volume
docker rm -f gen360-postgres
docker volume prune -f

# Remove .env
Remove-Item .env -ErrorAction SilentlyContinue

# Then follow the Quick Start again

11. Useful Commands Cheat Sheet

Docker / Database

# Start / stop / restart container
docker start gen360-postgres
docker stop gen360-postgres
docker restart gen360-postgres

# Check container status
docker ps -a --filter name=gen360-postgres

# View container logs
docker logs gen360-postgres --tail 50

# Open psql shell
docker exec -it gen360-postgres psql -U postgres -d normas

# Run a quick SQL query
docker exec gen360-postgres psql -U postgres -d normas -c "SELECT count(*) FROM norma"

# Backup database
docker exec gen360-postgres pg_dump -U postgres normas > backup.sql

# Restore database
Get-Content backup.sql | docker exec -i gen360-postgres psql -U postgres -d normas

API Server

# Start dev server with reload
python -m uvicorn api.main:app --host 0.0.0.0 --port 8000 --reload

# Test health
Invoke-RestMethod http://localhost:8000/health

# Test DB health
Invoke-RestMethod http://localhost:8000/health/db

# List public atos
Invoke-RestMethod "http://localhost:8000/public/atos?limit=5"

Admin Registration (via API)

# Step 1: Start registration → get MFA secret
$body = @{email="admin@test.com"; senha="Test@1234"} | ConvertTo-Json
Invoke-RestMethod -Uri http://localhost:8000/admin/register -Method POST -Body $body -ContentType "application/json"

# Step 2: Scan QR code with authenticator app, then confirm with MFA code
$body = @{email="admin@test.com"; senha="Test@1234"; mfa_secret="SECRET_FROM_STEP1"; mfa_code="123456"} | ConvertTo-Json
Invoke-RestMethod -Uri http://localhost:8000/admin/register/confirm -Method POST -Body $body -ContentType "application/json"

# Step 3: Login
$body = @{email="admin@test.com"; senha="Test@1234"; mfa_code="123456"} | ConvertTo-Json
Invoke-RestMethod -Uri http://localhost:8000/admin/login -Method POST -Body $body -ContentType "application/json"
